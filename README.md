# 走进科学之：为什么机器人跳舞比不过小姐姐？

《从"翩若惊鸿"到具身智能：为什么真正的轻盈，背后全是力量》的网页版。

> 越显得轻盈，往往越需要力量。

在线访问：**https://fangde.github.io/robot-dance/**

## 这是什么

一篇关于人形机器人运动能力的科普长文（约 10,700 字）。从《洛神赋》的"翩若惊鸿"讲到

- 舞蹈为什么是人对生命的审美
- 生物运动感知（biological motion）与世界模型
- 力量 / 体重比：为什么显得轻反而需要力量
- 丝滑的成因，以及梅西的起停与变向
- 机器人执行器的重量循环、灵巧手与腱驱传动
- 轻量化为什么既是性能也是安全
